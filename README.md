# research-html-report

> 单页研究报告 HTML 生成器 · "编辑研究风"（Editorial Research Style）
> A local Claude Code skill — turn research into a polished single-page HTML briefing.

把一次公司调研 / 行业研究 / 尽调分析的结果，变成一份**老板 10 分钟能读完、且读得下去**的单页 HTML：
浅纸底、国际蓝、Mono 编号、细边框卡片、Chart.js 图表；零构建依赖，一个 `.html` 文件直接分享。

## 效果样例

- `产出/腾盛智能-AI融合调研与董事长沟通简报-20260917.html`（消防橙主题 · 公司调研+沟通简报）
- `产出/深圳市轮动科技有限公司-调研分析报告.html`（国际蓝主题 · 公司尽调）

## 设计语言

| 元素 | 规格 |
|---|---|
| 底色 / 墨色 | `#fafaf8` 纸张色 / `#0a0a0` |
| 默认主色 | 国际蓝 `#002FA7`，另有 `fire` 消防橙 / `green` 墨绿 / `wine` 酒红，一行 `<body data-theme>` 切换 |
| 字体 | Inter + PingFang SC（正文）／JetBrains Mono（数字与编号） |
| 标题 | 细字重 200–300 + 大字号 + 负字距（编辑感来源） |
| 图表 | Chart.js 4.4，jsdelivr/unpkg 双源 fallback；单色不彩虹、负值自动红、禁双轴 |
| 其他 | 无阴影堆砌、无 emoji、无渐变装饰；深色块全篇 ≤3 处；内置响应式 + 打印/PDF 样式 |

## 组件清单（全部在 `assets/template.html` 里有示例）

Hero · KPI 数字带（4/5/6 格）· 洞察框 · 业务卡片网格 · 业务表 · 痛点五连格 ·
分组机会卡（带难度圆点/首推角标）· 价值×难度气泡矩阵 · 三步路径时间轴 ·
案例硬数据表 · 政策卡 · 深色话术框 · 沟通四步 · DO/DON'T 双卡 · 来源页脚

## 使用方式（给 Claude Code）

安装到 `~/.claude/skills/research-html-report/` 后，直接说：

- "出一份 XX 公司的调研报告，HTML"
- "调研一下 XX 行业 / 这家公司，给老板看"
- "做一份拜访 XX 董事长的会前简报"

Claude 会：收集事实并区分"已核实 / 宣传口径 / 推测" → 复制模板到 `产出/` →
按标准结构取舍章节 → 填内容、配图表 → 自查清单 → 自动 `open`。

## 文件结构

```
research-html-report/
├── SKILL.md            # 触发规则、写作原则、结构与自查清单（Claude 读这个）
├── README.md           # 本文件（给人看的）
└── assets/
    └── template.html   # 唯一模板本体：全部 CSS + 组件占位 + 图表示例
```

## 设计原则

1. **结论先行**：标题就是结论，正文是证据
2. **事实与推测分离**：来源可追溯，宣传口径必须标注，页脚固定免责区
3. **数字优先**：能用 KPI 卡和图表说的，不写段落
4. **克制**：深色块只留给"必须停下来读"的判断

## 不适用场景

对外客户方案（走飞书云文档）、PPT/课件、个股投资分析（另有"君正款"白底风格）、
省/市区域产业报告（另有"江苏款"）、用户明确指定其他风格时。
